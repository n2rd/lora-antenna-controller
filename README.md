# Building the LoRa Antenna Controller as in QST November 2026

There are two components:
* a Shack Unit that provides the user interface in the shack
* a Field Unit that interfaces with the 4 Square Antenna Controller

There is a subfolder for each that has the code, firmware binary, and STL files for printing a case for the unit.

There are more details in the README.md files in each subfolder.
